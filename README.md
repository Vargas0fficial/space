# Vargas Works Personal Website

## Overview
This is a personal website for Vargas Works, showcasing skills, portfolio, and contact information.

## Files
- `index.html`: The main HTML file.
- `styles.css`: The CSS file for styling the website.
- `script.js`: The JavaScript file for adding interactivity.

## How to Run
1. Open `index.html` in a web browser.
2. Enjoy browsing the personal website!
